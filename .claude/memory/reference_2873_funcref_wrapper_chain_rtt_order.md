# Funcref-wrapper struct RTT identity is ORDER-dependent — casts to a non-root wrapper are unsafe (#2873 park)

- All no-capture closure wrapper structs are layout-identical `(struct (field funcref))`, but `getOrCreateFuncRefWrapperTypes` chains every later signature `sub final` under the FIRST wrapper created (star topology). WasmGC isorecursive canonicalization keys on (fields, supertype, finality) → siblings do NOT merge. The old `#1131` comment "V8 canonicalizes same-layout structs, so this cast succeeds" is FALSE for the chain.
- Consequence: `ref.test/ref.cast (ref <declared-sig wrapper>)` on a closure value allocated under a DIFFERENT signature's wrapper nulls out unless the target happens to be the chain root — i.e. correctness depended on wrapper-CREATION ORDER (which helper compiled first).
- Bit hardest via async activation: it rewrites the closure result to externref (Promise), so value-site wrapper = externref-sig while a `fn: () => void` typed param casts to the void-sig wrapper → cast null → funcref fetch traps ("dereferencing a null pointer in asyncTest()") — the 32-file null_deref cluster that parked PR #2873. Same latent hazard for covariant SYNC closures (`() => string` as `() => void`).
- Fix pattern (calls.ts callable-param dispatch): cast the externref callee to the wrapper ROOT (`getFuncRefWrapperRootTypeIdx`), `struct.get` the funcref off the root, discriminate on the funcref's exact type (encodes the true signature), re-cast self per matched arm. NOTE: the property-call dispatch (calls-closures.ts ~682/874) still casts to the declared wrapper — same latent hazard, no corpus hit yet.
- Sibling hazard (same park, 5 wasm_compile): async frame SPILL fields are typed from TS declarations BEFORE body compile, but body compile can rebind locals (nested-fn mutable capture → CELL-BOX; ref-typed guesses diverge from inferred reps, e.g. #3134 Promise-unwrap vec elements) → `struct.set[1] expected i32, found (ref null N)`. Guard: `asyncClosureCellSpillHazard` (async-frame.ts) declines host-drive for those closure shapes; declaration lane carries the same latent hazard (no corpus instance).
