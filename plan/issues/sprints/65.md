## Retrospective — sprint 65

**What worked**

  remainder) repeatedly turned 1,000+-row "epics" into small landable fixes
  (#2158, #56, the tag-5 cascade).
- The merge_group standalone floor (#2097) as the single authoritative gate for
  broad-impact value-rep / construct-dispatch changes.

  net-negative work before it shipped (#74, #2614, #2613).
- One-shot enqueue + never-re-enqueue-on-eject + fix-forward kept the merge queue
  from churning.

  nearly parked as a multi-day dispatcher build because the senior tested the wrong
  bridge. Let the floor arbitrate small testable hypotheses cheaply.

  git state + timeouts.
