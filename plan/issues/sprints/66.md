remaining walls are tight and well-characterized:

- **#1712** *(in-progress)* — the acceptance umbrella (differential-AST gate vs
  node-acorn). Carried s64 → s66. Becomes runnable once `parse()` returns a
  `Program` AST.
- **#2657** *(in flight, PR #2038)* — tokenizer hang: `this.pos` is READ via a
  typed `struct.get` slot but WRITTEN via `__extern_set` (JS sidecar), so the
  slot freezes at 0 and the scan loop never advances. Fix = symmetric
  `struct.set` write dispatch (codegen-clean; the current unblock).
- **#2656** *(ready, depends_on #2657)* — `parseStatement` `switch(this.type)` on
  an externref token-type fails `===` identity vs the `tt` singleton → infinite
  re-entry, `next()` never called. The next wall once #2657 lands.
- **#2628** *(backlog)* — method-call-on-construct-closure-result; re-grounded as
  host-side-only, NOT dogfood-blocking.

standalone (`--target wasi`)**. Drive via the deep-tracing dev that root-caused
