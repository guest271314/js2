# Acorn differential corpus — gap map (#1712 umbrella)

Generated by `tests/dogfood/acorn-corpus.mjs` (run: `pnpm run dogfood:acorn-corpus`)
against **current main** (acorn@8.16.0 pinned), **re-run 2026-07-17**. All the
2026-06-30 REAL gaps (#2841/#2851/#2852/#2846/#2850) have since landed.

The harness compiles the pinned acorn entry module **once**
(`skipSemanticDiagnostics: true`), instantiates it, `wrapExports`, then diffs
`parse(input)` for every corpus input against node-acorn (the **same** pinned
tarball = oracle, zero version skew) with `diffAst({ maxDivergences: 100000 })`
— **UNCAPPED** (the default cap of 8 hid real divergences twice in prior
sessions). Each divergence is classified **QUIRK** (cosmetic host-marshalling:
`sourceFile` extra field, booleans as i32 0/1) vs **REAL** (everything else).

## In-Wasm vs host-boundary — E0 arbitration (#3308)

The host-boundary numbers above measure `wrapExports` marshalling. The #2928
bytecode interpreter instead consumes the AST **in-Wasm** via dynamic `$Object`
field reads. E0 (`pnpm run dogfood:acorn-probe`, `tests/dogfood/acorn-probe.mjs`)
compiles a TS walker **alongside** acorn in one module and reads node fields
in-Wasm, returning only scalars. Arbitration of the three suspected
marshalling-only gaps, on **element-field integrity** (not just container length):

| gap   | field checked in-Wasm                     | host-boundary (2026-07-17) | in-Wasm read (E0) | verdict                                                   |
| ----- | ----------------------------------------- | -------------------------- | ----------------- | --------------------------------------------------------- |
| #2841 | Function/Arrow `params[i].type` / `.name` | equal (landed)             | **intact**        | host-marshalling-only — **off interpreter critical path** |
| #2851 | TemplateLiteral `quasis[i].value.cooked`  | equal (landed)             | **intact**        | host-marshalling-only — off critical path                 |
| #2852 | SequenceExpression `expressions[i].type`  | equal (landed)             | **intact**        | host-marshalling-only — off critical path                 |

All three read **intact in-Wasm** on both crafted single constructs and the
representative corpus files (`arrow-params.js`/`sequence-misc.js`/`templates.js`),
so they do **not** block the #2928 interpreter.

**E0 also surfaced a NEW in-Wasm-only limit (→ #3343):** a _full recursive_ walk
of a larger parse (~60+ nodes) runs away (spurious back-edge at scale), while
single constructs walk with ±0 node-count parity (15/15) and isolated/indexed
reads are faithful. This is invisible at the host boundary (which marshals the
whole tree out once) and is the next substrate gate for the E2 emitter. Tracked
in **#3343**.

## Suspected shared root cause (marshalling family)

The dominant grouped signatures are `missing-field @ .type` (×58) and
`missing-field @ .name` (×35), spanning #2841 (`params[]`), #2851 (`quasis[]`),
and #2852 (`expressions[]`). All three are "node-typed **elements of a specific
array property** come back without their fields" — one likely shared
`wrapExports` array-of-struct marshalling fix. Cross-referenced in each issue so
a dev can consolidate.
